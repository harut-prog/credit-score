# План завершения ДЗ 3

1. На ветке `hw3` временно запускать `tests → build → deploy` по push в `hw3`. Базовый deploy должен завершиться зелёным: Registry champion, Ingress, prediction и точная строка PostgreSQL.
2. Отдельный коммит с отсутствующим `MODEL_ALIAS`: при deploy новый Pod не становится Ready, rollout красный; следующий коммит возвращает `champion` и даёт зелёный run.
3. Отдельный коммит с неверным `KIND_CLUSTER`: job красный на `kind export kubeconfig`; следующий коммит возвращает правильное имя и даёт зелёный run.
4. Отдельный коммит с несовпадающим host в `k8s/ingress.yaml`: rollout успешен, smoke получает HTTP 404; следующий коммит возвращает `credit.localhost` и даёт зелёный run.
5. Для всех шести запусков записать ссылки, фактический шаг и текст ошибки в `REPORT.md`. Обновить статус инструкции и выполнить финальную проверку ветки.
6. Добавить настоящие скриншоты GitHub Settings, MLflow и k9s, когда авторизованные страницы доступны; без них этот критерий остаётся непроверенным. Не создавать синтетические скриншоты интерфейсов.

Критерий завершения кода: `git status` без незакоммиченных изменений отслеживаемых файлов; все новые коммиты только в `hw3`; последний deploy из `hw3` зелёный. Критерий полного отчёта: ссылки на конкретные runs и обязательные снимки экрана.
